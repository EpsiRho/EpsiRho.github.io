FreakFreq

A super customizable audio visualizer for windows!

WindowsC#AudioWPFData VisualizationFVZ

Links

GithubBlog PostMicrosoft Store
June 29, 2025

FreqFreak is an application made in WPF that can take in audio from WASAPI loopback for output, input, and per process id and show it with pretty and customizable audio visualizations. Tons of options, multiple built in bin mappings, easy saving/loading of config files, and many color/size/shape customizations for the spectrum. This was a labor of love as someone who grew up placing visualizers into my desktop backgrounds using Rainmeter way back in the day. As Rainmeter seems to be mostly out of fashion and many of it's popular visualizers now being broken or dead in some way, I wanted a new way to make visualizations on my PC. You can read more about the dev process and the how it works on the Blog Post! It's all free, as is it's codebase. Feel free to add / fix things or use it to build up your own visualizing systems :D

Changelog: v2.0.13

  • Fixed a regression in Photo Cutouts (I fixed a bug and then managed to merge it back in)
  • Some PCs experienced a flicker in gradient settings, this should be fixed now!

v2.0.12 (GitHub Only Release)

  • You can now toggle pitch + frequency peak tracking
  • Fixed Outer Circle and Inner Circle modes not showing peaks unless in stereo mode.

v2.0.11

  • The AudioDevices window crash due to a weak reference to it's Dispatcher has been fixed
  • The Lines in centered mode were being drawn incorrectly on the right side with 2 stray points, these points are now gone
  • The Cutouts can now use the arrow keys for nudging just like the main Visualizer.
  • PathGeometry Memory Leak fixed
  • Line Brush Memory Leak fixed
  • Color system is now more performant

v2.0.10

  • Dual Channel visualizations
    • Add Left Channel/Right Channel/Stereo/Mono selector
    • Add Oscilloscope Visualization (Stereo Mode only)
    • Stereo Mode for Centered
    • Stereo Mode for Inner/Outer Circle
  • Add Pitch Tracking + Color effect
    • Current Pitch Guess + Note Guess + Peak Frequency Guess in the Options Window
    • Pitch color modes show the current pitch guess as a color on the gradient between color 1-2 or a rainbow gradient.
    • Frequency color modes show the current frequency peak guess as a color on the gradient between color 1-2 or a rainbow gradient.
    • Pitch/Peak guess is ONLY SEMI ACURATE, and can become more or less accurate depending on your FFT settings. It is also based off a mono representation of the audio in stereo mode, although in left/right exclusive modes it will base of the specified channel.
  • Revamped Color Modes
    • Single Color
    • Dual Color Gradient Vertical, Horizontal, Height, Pitch, or Frequency
    • Custom N-Color Gradient Vertical, Horizontal, Height, Pitch, or Frequency
      • To support custom gradients, a new Gradient Editor was added with some presets
  • New Visualization Options + Modes
    • Show As Lines shows the bars as points on a line(s) instead of bars
    • Peaks now have a selector for mode:
      • Off, Peak Bars, Peak Lines, Peak Bars Only, Peak Lines Only
      • Low End Dampen lets you control how much to dampen the bass compared to the rest of the spectrum, since bass can often be overpowering in audio. The new default is 1.17 (from 1 aka no dampening)
    • Bass Reactive Scaling + Bass Reactive Shake
  • Tray Icon Additions
    • Open New Instance
    • Quick Import
    • Quick Access to Audio Input Switcher
    • Pause/Play Visualization
  • Options Menu Buttons moved from bottom to top, and a few new buttons added
    • Play/Pause (Stops the visualizer from getting new audio data)
    • New Instance (Opens a new visualizer instance)
    • Recenter (Brings the visualizer to be centered on the Options Window)
    • Export
    • Import
    • Audio Input Settings
    • FVZ Tool
    • Cutout Tool
  • Cutout Tool lets you place images anywhere on screen
    • Can be used to place images as decoration, or to cover up parts of the screen.
    • For example, cutting out the subject of the desktop background, and placing it's cutout overtop the visualizer, to give it depth.
    • Can also be Bass Reactive
  • Optimization Pass
    • Visualizations are now spread out across more threads:
    • Audio comes in and is built into frames on it's own thread on the CPU, while another CPU threads preps the window and takes those audio frames and turns them into GPU ready frames.
    • The GPU now handles rendering the visuals, improving FPS and making the maximum settings you can get away with larger.
    • The Options Window and it's subsequent windows are now given their own UI threads, instead of piggy backing off of the visualizer's. This means they no longer lock up when the visualizer lags now.
  • Audio Switcher can now be refreshed without reopening it
  • New Dark + Transparent style
    • Windows will now try and open out of the way of other FreqFreak Windows (to the top/left/right/bottom)
    • Accent + Tray icon color is now more consistently colorful
  • Keyboard nudging (you can use your arrow keys to nudge the selected visualizer window by 1 pixel for precise alignment)
